# BRUTALISM — Portfólio

Site portfólio oficial da **BRUTALISM**, estúdio de Design Gráfico e Edição de Vídeo.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântico, Acessível)
- **CSS3** (Variáveis CSS, CSS Grid, Flexbox, Animações puras, Responsive Design)
- **JavaScript ES6+** (Vanilla JS — sem dependências externas)
- **Google Fonts** (Space Mono & Space Grotesk)

## ⚡ Efeitos & Recursos

- 🖤 Estética Brutalista com bordas retas e alto contraste
- ⚡ Screen Loader interativo com contador
- 🎯 Custom Cursor responsivo
- 🔍 Lightbox Modal para visualização de projetos em tela cheia (com navegação por setas e teclado)
- 📝 Efeito de Glitch sutil no cabeçalho
- 🔄 Marquee horizontal contínuo com pausa no hover
- 📊 Contadores animados de estatísticas no manifesto
- 📱 Menu mobile responsivo
- ✉️ Form de contato com validação nativa
