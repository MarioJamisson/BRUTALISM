# 🖤 BRUTALISM: Vibe Coding & UI/UX de Alta Performance

Site portfólio oficial e *Digital Storefront* da **BRUTALISM**, estúdio de Design Gráfico e Edição de Vídeo. 

Este projeto atua como uma vitrine técnica, demonstrando como a orquestração de **Inteligência Artificial (Vibe Coding)** pode ser utilizada para construir interfaces web com alto rigor estético e micro-interações complexas sem a necessidade de frameworks pesados (como React ou Vue).

🔗 **Deploy em Produção:** [Acessar Brutalism](https://mariojamisson.github.io/BRUTALISM/)

## 🎯 O Problema e a Solução (Case Técnico)

* **O Desafio:** Traduzir uma identidade visual não-convencional (Brutalismo) — que exige alto contraste, tipografia rústica, animações customizadas e layouts assimétricos — em código funcional e responsivo, sem comprometer a performance da página com bibliotecas externas de animação.
* **A Solução:** Um portfólio imersivo e ultraleve construído puramente com Vanilla JavaScript e CSS3. A interface garante uma experiência de marca forte e retenção visual.
* **Impacto e IA (Vibe Coding):** A construção de componentes complexos, como o *Custom Cursor*, modais de *Lightbox* e o efeito de *Glitch*, foi iterada e acelerada através de ferramentas de geração de código por IA (Prompting avançado). Este repositório prova a capacidade de converter wireframes e ideias criativas em produtos web reais e de vanguarda em poucos dias, dominando o front-end na sua forma mais pura.

## ⚡ Experiência de Utilizador & Micro-interações

As funcionalidades abaixo foram implementadas focando na interatividade e retenção do utilizador:

* 🎯 **Custom Cursor Responsivo**: Um cursor adaptativo que reage aos elementos da página, aumentando o engajamento tátil.
* 🔍 **Lightbox Modal Modal Avançado**: Visualização imersiva de projetos em tela cheia (com navegação fluida por setas e teclado).
* 📝 **Geração Dinâmica de Efeitos**: Implementação matemática de efeitos de Glitch no cabeçalho e contadores animados de estatísticas para reter a atenção.
* 🔄 **Marquee Contínuo**: Faixas de texto de rolagem horizontal com controle de pausa no hover, otimizadas por GPU para zero travamentos.
* ⚡ **Screen Loader Interativo**: Feedback visual imediato durante o carregamento, diminuindo a taxa de rejeição (*bounce rate*).

## 🛠️ Tecnologias & Engenharia de Front-End

Este projeto aplica a filosofia de desenvolvimento de construir "apenas o necessário", utilizando o poder do navegador sem dependências desnecessárias:

* **Markup & Estilo**: HTML5 Semântico e CSS3 Moderno (Variáveis, CSS Grid, Flexbox). Animações `keyframes` puras.
* **Lógica de Interface**: JavaScript ES6+ (Vanilla JS). Toda a gestão de estado dos modais, cursores e formulários foi feita nativamente.
* **Tipografia**: Integração com Google Fonts (Space Mono & Space Grotesk).

## 📂 Como Executar (Zero Setup)

A arquitetura *framework-less* permite a execução instantânea em qualquer ambiente.

1. Clone o repositório.
2. Abra o `index.html` no seu navegador favorito.
3. Não há etapas de *build* ou pacotes NPM (`node_modules`). O código já está otimizado e pronto para produção.
